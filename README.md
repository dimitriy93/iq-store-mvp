# iq-store-mvp

MVP интернет-магазина IQOS. Frontend на React и backend на Node.js с каталогом товаров, корзиной, оформлением заказа, историей заказов и Bluetooth-разделом.

## Стек

### Frontend

- React 19
- TypeScript
- Vite
- MobX
- SCSS

### Backend

- Node.js
- TypeScript
- SQLite
- Knex
- fast-xml-parser

## Возможности

- каталог товаров с изображениями;
- фильтрация по категориям с навигацией по дереву;
- пагинация каталога и истории заказов;
- корзина с изменением количества товаров;
- оформление заказа через backend API;
- сохранение заказов в SQLite;
- история заказов с пагинацией;
- очистка истории заказов;
- Bluetooth-раздел.

## Данные каталога

Исходный публичный product feed на момент разработки недоступен. Для воспроизводимости тестового задания используется локальная копия ранее доступного XML feed.

URL изображений, указанные в историческом feed, в настоящее время недоступны. Поэтому удалённые изображения не используются в интерфейсе.

Для визуализации каталога добавлены локальные изображения в `public/catalog/`. Изображение для каждого товара выбирается детерминированно на основе его ID: последняя цифра числовой части ID определяет индекс изображения `product-01.webp` — `product-10.webp`. Таким образом, один и тот же товар всегда получает одно и то же изображение, а каталог не зависит от доступности внешних ресурсов.

## API

```
GET    /api/catalog           — получение каталога товаров
POST   /api/orders            — создание заказа
GET    /api/orders?page=1&limit=10 — список заказов с пагинацией
DELETE /api/orders            — удаление всей истории заказов
```

## Запуск

### Backend

```bash
cd backend
npm install
npm run dev
```

Сервер запускается на `http://localhost:3000`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend проксирует запросы `/api` на backend в режиме разработки.

## База данных

- используется SQLite;
- миграции выполняются через Knex (`npm run db:migrate`);
- файл базы данных: `backend/database/iq-store.sqlite`;
- каталог товаров загружается из `backend/data/products.xml` на стороне backend.
